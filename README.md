
# AI Lecture Notes Summarizer

## Project Overview
AI Lecture Notes Summarizer is a Python application that helps
students understand lecture notes by processing uploaded PDF files.

## Features
- Upload lecture notes in PDF format
- Generate a summary of the document
- Extract important key points
- Generate flashcards for revision

## Technologies Used
- Python
- Streamlit
- PDF text extraction library
- AI/NLP library or API used by the application

## Installation
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Configure any required API keys locally.
5. Run the application.

## Run the Application
streamlit run app.py
